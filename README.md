# Northfold Stoneware Mug

A responsive product page for the Northfold Stoneware Mug, priced at $28.

## Features
- Product image gallery and three glaze options.
- Quantity input and Add to cart button.
- Responsive layout for desktop and mobile.
- Semantic HTML and accessible form controls.

## Design decision
I used CSS Grid to arrange the product gallery and details because it supports the required two-column desktop layout and single-column mobile layout.

## Next steps
Improve the product photography, complete accessibility testing and add cart functionality in a future iteration.

## Run locally
Open `index.html` in a web browser.
